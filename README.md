## Quickstart:
1. Invite bot with these permissions in [OAuth2](https://discord.com/developers/home) tab:
   1. Kick Members
   2. Ban Members
   3. Moderate Members
   4. Send Messages
   5. Manage Messages
2. Copy [.env.example](.env.example) and create your own .env variant
3. ```docker compose up --build```
